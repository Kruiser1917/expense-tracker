# Трекер расходов

Консольная программа на чистом Python для учёта личных трат: добавляет расходы, показывает историю и сводку по категориям, следит за месячным лимитом. Данные сохраняются в JSON между запусками. Для работы не нужны сторонние библиотеки, pytest — только для тестов.

## Запуск

Нужен Python 3.10 или новее (проверено на 3.14).

```bash
git clone https://github.com/Kruiser1917/expense-tracker.git
cd expense-tracker
python3 main.py
```

Выход — пункт `0` или Ctrl+C. Данные сохраняются в `expenses.json` рядом с `main.py` после каждого действия.

## Что реализовано

Обязательные требования:

- [x] меню работает в цикле до команды выхода
- [x] у каждой траты есть дата, категория, сумма и комментарий
- [x] ввод проверяется: неверная дата, пустая категория, сумма не числом или ≤ 0 — программа переспрашивает и не падает
- [x] данные сохраняются между запусками в JSON
- [x] общая сумма и разбивка по категориям с долями в процентах
- [x] самая крупная трата и фильтр по категории
- [x] логика разделена на модули, классы и функции
- [x] README с инструкцией и примерами

Дополнительно:

- [x] месячный лимит с предупреждением о превышении
- [x] редактирование и удаление трат
- [x] сортировка по дате и по сумме
- [x] тесты на pytest: 29 проверок на обычных, граничных и ошибочных данных
- [x] экспорт сводки в CSV через модуль `csv`
- [x] защита данных: запись через временный файл; повреждённый `expenses.json` не затирается, а сохраняется как `expenses.json.broken`

## Структура проекта

```
expense-tracker/
├── main.py              меню, ввод и вывод
├── models.py            Transaction и BudgetTracker: данные, проверки, подсчёты
├── storage.py           сохранение и загрузка JSON, экспорт сводки в CSV
├── tests/               тесты pytest
├── pyproject.toml       настройки pytest
└── requirements-dev.txt зависимости для разработки
```

## Формат данных

`expenses.json`:

```json
{
  "monthly_limit": 5000.0,
  "transactions": [
    {"date": "2026-10-20", "category": "такси", "amount": 3000.0, "comment": "аэропорт"}
  ]
}
```

Категории приводятся к нижнему регистру: «Такси» и «такси» считаются одной категорией.
